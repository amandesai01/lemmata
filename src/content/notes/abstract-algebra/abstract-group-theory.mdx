## Three motivating examples

<Video id="PN-cro0J_v8" title="Motivational examples of groups" duration="37:59" />

Groups are algebraic objects that abstract certain features shared by familiar mathematical objects.
Each of the following three examples is a set together with a way of combining two of its elements
into a third, and in each the same four properties of that combination appear.

<Example n="1.1" title="The integers under addition">
Let ℤ = \{…, −2, −1, 0, 1, 2, …\} be the set of integers, with addition. Addition has four properties.

1. *Closure:* the sum of two integers is an integer. Addition takes two integers as input and gives one
   integer as output, so it is a binary operation on ℤ.
2. *Identity:* *n* + 0 = 0 + *n* = *n* for every integer *n*, and 0 is the only integer with this
   property. It is the identity element for addition.
3. *Inverses:* every integer *n* has an inverse −*n*, with *n* + (−*n*) = 0.
4. *Associativity:* (*l* + *m*) + *n* = *l* + (*m* + *n*) for all integers *l*, *m*, *n*. A sum of three
   integers therefore has one value however its terms are grouped: (3 + 2) + 5 = 5 + 5 = 10 and
   3 + (2 + 5) = 3 + 7 = 10.

Addition has a fifth property, *m* + *n* = *n* + *m*, but it is not among those kept.
</Example>

These properties are not automatic. Under multiplication, ℤ has no inverses: the only number whose
product with 2 is 1 is 1/2, which is not an integer.

<Definition n="1.2" title="Bijection">
A function *f* : *X* → *Y* is **one-to-one** if distinct elements of *X* have distinct images, and
**onto** if every element of *Y* is the image of some element of *X*. It is a **bijection** if it is
both one-to-one and onto.
</Definition>

Let *S*<sub>3</sub> be the set of all bijections from \{1, 2, 3\} to itself. Nothing about 1, 2 and 3
is used except that they are three distinct elements.

<Example n="1.3" title="The six bijections of a three-element set">
The elements of *S*<sub>3</sub> are the following six functions.

1. *f*<sub>1</sub> : 1 ↦ 1, 2 ↦ 2, 3 ↦ 3, the identity function;
2. *f*<sub>2</sub> : 1 ↦ 2, 2 ↦ 1, 3 ↦ 3, which interchanges 1 and 2;
3. *f*<sub>3</sub> : 1 ↦ 3, 2 ↦ 2, 3 ↦ 1, which interchanges 1 and 3;
4. *f*<sub>4</sub> : 1 ↦ 1, 2 ↦ 3, 3 ↦ 2, which interchanges 2 and 3;
5. *f*<sub>5</sub> : 1 ↦ 2, 2 ↦ 3, 3 ↦ 1;
6. *f*<sub>6</sub> : 1 ↦ 3, 2 ↦ 1, 3 ↦ 2.

There are no others. A bijection that fixes one of 1, 2, 3 either fixes the other two as well or
interchanges them, so it is one of *f*<sub>1</sub>, …, *f*<sub>4</sub>. A bijection *f* that fixes
nothing sends 1 to 2 or to 3. If *f*(1) = 2, then *f*(2) = 3, since *f*(2) = 1 would force *f*(3) = 3;
so *f* = *f*<sub>5</sub>. In the same way *f*(1) = 3 gives *f* = *f*<sub>6</sub>.
</Example>

The operation on *S*<sub>3</sub> is composition of functions. Since domain and codomain are the same,
any two elements can be composed. The composite *f* ∘ *g* applies *g* first and then *f*, and is
written *fg*.

<Example n="1.4" title="The order of composition matters">
Under *f*<sub>5</sub> the element 1 goes to 2, and under *f*<sub>2</sub> the element 2 goes to 1, so
*f*<sub>2</sub>*f*<sub>5</sub> sends 1 to 1. In the same way it sends 2 to 3 and 3 to 2, so

<Display>*f*<sub>2</sub>*f*<sub>5</sub> = *f*<sub>4</sub>.</Display>

On the other hand *f*<sub>5</sub>*f*<sub>2</sub> sends 1 to 3, 2 to 2 and 3 to 1, so
*f*<sub>5</sub>*f*<sub>2</sub> = *f*<sub>3</sub>. Unlike the addition of integers, composition in
*S*<sub>3</sub> depends on the order in which the two elements are taken.
</Example>

<Proposition n="1.5" title="Composition of the six bijections">
1. *Closure:* the composite of two bijections is a bijection, so composition is a binary operation
   on *S*<sub>3</sub>.
2. *Identity:* *ff*<sub>1</sub> = *f*<sub>1</sub>*f* = *f* for every *f* ∈ *S*<sub>3</sub>.
3. *Inverses:* *f*<sub>1</sub><sup>2</sup> = *f*<sub>2</sub><sup>2</sup> = *f*<sub>3</sub><sup>2</sup> =
   *f*<sub>4</sub><sup>2</sup> = *f*<sub>1</sub> and *f*<sub>5</sub>*f*<sub>6</sub> =
   *f*<sub>6</sub>*f*<sub>5</sub> = *f*<sub>1</sub>, so every element has an inverse.
4. *Associativity:* (*fg*)*h* = *f*(*gh*) for all *f*, *g*, *h* ∈ *S*<sub>3</sub>.
</Proposition>

<Proof>
For (i), let *f* and *g* be bijections. If *f*(*g*(*x*)) = *f*(*g*(*y*)) then *g*(*x*) = *g*(*y*), as *f*
is one-to-one, and then *x* = *y*, as *g* is; so *fg* is one-to-one. Given *z*, there is *y* with
*f*(*y*) = *z*, as *f* is onto, and *x* with *g*(*x*) = *y*, as *g* is; so *fg* is onto. Part (ii) holds
because *f*<sub>1</sub> moves nothing. For (iii), *f*<sub>2</sub> sends 1 to 2 and 2 back to 1 and
fixes 3, so *f*<sub>2</sub><sup>2</sup> fixes everything; *f*<sub>3</sub> and *f*<sub>4</sub> are
alike. The composite *f*<sub>5</sub>*f*<sub>6</sub> sends 1 to 3 and then to 1, 2 to 1 and then to 2,
and 3 to 2 and then to 3, and *f*<sub>6</sub>*f*<sub>5</sub> likewise fixes each element. For (iv),
both (*fg*)*h* and *f*(*gh*) send *x* to *f*(*g*(*h*(*x*))).
</Proof>

<Example n="1.6" title="Rotations of an equilateral triangle">
Take an equilateral triangle, as in [Fig. 1](#fig-1-caption), and rotate the plane about the triangle’s
centre. A **rotational symmetry** of the triangle is a rotation that carries the triangle onto itself.
A rotation through 90° is not one, but rotations anticlockwise through 120°, 240° and 360° are. Call
these *R*<sub>2</sub>, *R*<sub>3</sub> and *R*<sub>1</sub>; the rotation *R*<sub>1</sub> through 360°
is the same as a rotation through 0°, and moves nothing. Let

<Display>*G* = \{*R*<sub>1</sub>, *R*<sub>2</sub>, *R*<sub>3</sub>\},</Display>

with composition as its operation. Composing two rotations adds their angles:
*R*<sub>2</sub>*R*<sub>3</sub> = *R*<sub>3</sub>*R*<sub>2</sub> = *R*<sub>1</sub>, since 120° + 240° =
360°; *R*<sub>2</sub>*R*<sub>2</sub> = *R*<sub>3</sub>; and *R*<sub>3</sub>*R*<sub>3</sub> =
*R*<sub>2</sub>, since 480° is a full turn and 120° more. So composition is a binary operation on
*G*. The rotation *R*<sub>1</sub> is an identity element; *R*<sub>2</sub> and *R*<sub>3</sub> are
inverses of each other, and *R*<sub>1</sub> is its own inverse; and composition is associative, as
composition of functions always is.
</Example>

In each of the three examples, a set carries a binary operation that has an identity element, under
which every element has an inverse, and which is associative. These four properties define a group.

## The definition of a group

<Video id="-tP-cxErI-A" title="Definition of a group and examples" duration="26:05" />

<Definition n="2.1" title="Binary operation">
A **binary operation** on a set *G* is a function ∗ : *G* × *G* → *G*, written (*g*<sub>1</sub>,
*g*<sub>2</sub>) ↦ *g*<sub>1</sub> ∗ *g*<sub>2</sub>.
</Definition>

Since *g*<sub>1</sub> ∗ *g*<sub>2</sub> lies in *G* again, closure is part of being a binary operation.

<Definition n="2.2" title="Group">
A **group** (*G*, ∗) is a set *G* with a binary operation ∗ satisfying three axioms:

1. *identity:* there is an element *e* ∈ *G* with *g* ∗ *e* = *e* ∗ *g* = *g* for all *g* ∈ *G*;
2. *inverses:* each *g* ∈ *G* has an element *g*<sup>−1</sup> ∈ *G* with *g* ∗ *g*<sup>−1</sup> =
   *g*<sup>−1</sup> ∗ *g* = *e*;
3. *associativity:* (*g*<sub>1</sub> ∗ *g*<sub>2</sub>) ∗ *g*<sub>3</sub> = *g*<sub>1</sub> ∗
   (*g*<sub>2</sub> ∗ *g*<sub>3</sub>) for all *g*<sub>1</sub>, *g*<sub>2</sub>, *g*<sub>3</sub> ∈ *G*.
</Definition>

The identity element must exist before inverses can be defined. A set alone is not a group: a group
is a set together with its operation. When the operation is clear from the context, one says simply
that *G* is a group. Such a group is **abstract**: its elements need not be numbers, functions or
rotations, and nothing is assumed of them beyond what the axioms impose.

<Example n="2.3" title="First examples">
The integers ℤ under addition, the bijections *S*<sub>3</sub> under composition, and the rotations of
the equilateral triangle in Example 1.6 under composition are groups. So are the rational numbers ℚ,
the real numbers ℝ and the complex numbers ℂ, each under addition: the sum of two rational, real or
complex numbers is again one, 0 is an identity, each *x* has the inverse −*x* (the inverse of 1/2 is
−1/2), and addition is associative.
</Example>

<Example n="2.4" title="The integers under multiplication">
Multiplication on ℤ is closed, it is associative, and 1 is an identity, since *n* · 1 = 1 · *n* = *n*
for every integer *n*, including 0. But 2 has no inverse: the only number *x* with 2*x* = 1 is 1/2,
which is not an integer. So ℤ is not a group under multiplication.
</Example>

<Example n="2.5" title="The rationals under multiplication">
In ℚ under multiplication, 2 has the inverse 1/2, and indeed every non-zero *r* ∈ ℚ has the inverse
1/*r*. Multiplication is closed and associative, and 1 is an identity. But 0 has no inverse, since
0 · *x* = 0 ≠ 1 for every *x*. So ℚ is not a group under multiplication.
</Example>

<Example n="2.6" title="Non-zero and positive numbers under multiplication">
Let ℚ<sup>∗</sup> = ℚ ∖ \{0\} be the set of non-zero rational numbers, and ℝ<sup>∗</sup> and
ℂ<sup>∗</sup> the sets of non-zero real and complex numbers. Each is a group under multiplication: a
product of non-zero numbers is non-zero, 1 is an identity, each *r* has the inverse 1/*r*, which is
defined because *r* ≠ 0, and multiplication is associative.

Let ℚ<sup>+</sup> and ℝ<sup>+</sup> be the sets of positive rational and positive real numbers. Each is
also a group under multiplication: a product of positive numbers is positive, the identity 1 is
positive, and the inverse of a positive number is positive.

The set ℤ<sup>∗</sup> = ℤ ∖ \{0\} of non-zero integers, however, is not a group under multiplication,
since 2 still has no inverse in it.
</Example>

<Example n="2.7" title="The operation matters">
None of ℚ<sup>∗</sup>, ℝ<sup>∗</sup>, ℂ<sup>∗</sup>, ℚ<sup>+</sup> and ℝ<sup>+</sup> is a group under
addition. The only number *e* with *e* + *x* = *x* is 0, and 0 does not belong to any of these sets.
</Example>

Whether a set is a group depends on its operation: the same set can be a group under one operation and
not under another. To specify a group is to specify its operation.

## Symmetric groups, roots of unity and matrices

<Video id="S0hA-iWCp4g" title="More examples of groups" duration="24:25" />

There is nothing special about the number 3 in the definition of *S*<sub>3</sub>.

<Definition n="3.1" title="Symmetric group">
For a positive integer *n*, *S*<sub>*n*</sub> is the set of bijections of \{1, 2, …, *n*\} to itself,
with composition as its operation. It is the **symmetric group on *n* letters**.
</Definition>

<Proposition n="3.2" title="The symmetric group is a group">
*S*<sub>*n*</sub> is a group under composition.
</Proposition>

<Proof>
The composite of two bijections is a bijection, by the argument for Proposition 1.5 (i). The identity
function, which sends each *k* to itself, is an identity element. If *σ* is a bijection, each *j* in
\{1, …, *n*\} equals *σ*(*i*) for exactly one *i*; setting *σ*<sup>−1</sup>(*j*) = *i* defines a
bijection with *σσ*<sup>−1</sup> = *σ*<sup>−1</sup>*σ* equal to the identity. Composition of
functions is associative.
</Proof>

<Definition n="3.3" title="Roots of unity">
A complex number *z* is an ***n*th root of unity** if *z*<sup>*n*</sup> = 1, and a **primitive *n*th
root of unity** if moreover *z*<sup>*m*</sup> ≠ 1 for 0 &lt; *m* &lt; *n*.
</Definition>

For a positive integer *n* let

<Display>*θ*<sub>*n*</sub> = cos(2π/*n*) + *i* sin(2π/*n*).</Display>

Since (cos *α* + *i* sin *α*)<sup>*m*</sup> = cos *mα* + *i* sin *mα*, the power
*θ*<sub>*n*</sub><sup>*m*</sup> is cos(2π*m*/*n*) + *i* sin(2π*m*/*n*). For *m* = *n* this is
cos 2π + *i* sin 2π = 1, while for 0 &lt; *m* &lt; *n* the angle 2π*m*/*n* lies strictly between 0 and
2π, so the power is not 1. Thus *θ*<sub>*n*</sub> is a primitive *n*th root of unity.

<Proposition n="3.4" title="The group of nth roots of unity">
The set

<Display>*G*<sub>*n*</sub> = \{1, *θ*<sub>*n*</sub>, *θ*<sub>*n*</sub><sup>2</sup>, …, *θ*<sub>*n*</sub><sup>*n*−1</sup>\}</Display>

is a group under multiplication, the **group of *n*th roots of unity**. Each of its elements is an
*n*th root of unity.
</Proposition>

<Proof>
Write *θ* for *θ*<sub>*n*</sub>. For 0 ≤ *j*, *k* ≤ *n* − 1 the product *θ*<sup>*j*</sup>*θ*<sup>*k*</sup>
is *θ*<sup>*j*+*k*</sup>. If *j* + *k* ≥ *n*, then *θ*<sup>*j*+*k*</sup> =
*θ*<sup>*n*</sup>*θ*<sup>*j*+*k*−*n*</sup> = *θ*<sup>*j*+*k*−*n*</sup> with 0 ≤ *j* + *k* − *n* ≤
*n* − 2; for example *θ*<sup>*n*−1</sup>*θ*<sup>2</sup> = *θ*<sup>*n*</sup>*θ* = *θ*. In either case
the product lies in *G*<sub>*n*</sub>, so multiplication is closed. The identity is 1 = *θ*<sup>0</sup>.
For 1 ≤ *k* ≤ *n* − 1 the inverse of *θ*<sup>*k*</sup> is *θ*<sup>*n*−*k*</sup>, since
*θ*<sup>*k*</sup>*θ*<sup>*n*−*k*</sup> = *θ*<sup>*n*</sup> = 1. Multiplication of complex numbers is
associative. Finally (*θ*<sup>*k*</sup>)<sup>*n*</sup> = (*θ*<sup>*n*</sup>)<sup>*k*</sup> =
1<sup>*k*</sup> = 1.
</Proof>

Not every element of *G*<sub>*n*</sub> is a primitive *n*th root of unity: 1 is never one when *n* > 1.

<Example n="3.5" title="The fourth roots of unity">
For *n* = 4, *θ*<sub>4</sub> = cos(π/2) + *i* sin(π/2) = *i*, the square root of −1. Then
*θ*<sub>4</sub><sup>2</sup> = −1 and *θ*<sub>4</sub><sup>3</sup> = −*i*, so

<Display>*G*<sub>4</sub> = \{1, *i*, −1, −*i*\}.</Display>
</Example>

The *n*th roots of unity lie on the unit circle in the complex plane: *θ*<sub>*n*</sub><sup>*k*</sup>
is the point at angle 2π*k*/*n* from the positive real axis. In particular *θ*<sub>*n*</sub> is at
angle 2π/*n*, and the fourth roots of unity are the four points 1, *i*, −1 and −*i*.

<Example n="3.6" title="Matrices under addition">
For positive integers *m* and *n*, let *M*<sub>*m*×*n*</sub>(ℝ) be the set of *m* × *n* matrices with
real entries. It is a group under entrywise addition: the sum of two *m* × *n* matrices is again one,
the zero matrix is the identity, the inverse of the matrix with entries *a*<sub>*jk*</sub> is the
matrix with entries −*a*<sub>*jk*</sub>, and addition is associative because addition of real numbers
is.
</Example>

Matrices can also be multiplied, but only when the number of columns of the first equals the number of
rows of the second: two 2 × 3 matrices cannot be multiplied. On the set *M*<sub>*n*</sub>(ℝ) of real
*n* × *n* matrices, multiplication is a binary operation. It is associative and the identity matrix
*I* is an identity element, but *M*<sub>*n*</sub>(ℝ) is not a group under multiplication, because not
every matrix has an inverse; the zero matrix has none.

<Definition n="3.7" title="General linear group">
GL<sub>*n*</sub>(ℝ) is the set of invertible *n* × *n* matrices with real entries.
</Definition>

<Proposition n="3.8" title="The general linear group is a group">
GL<sub>*n*</sub>(ℝ) is a group under matrix multiplication.
</Proposition>

<Proof>
If *A* and *B* are invertible, then (*AB*)(*B*<sup>−1</sup>*A*<sup>−1</sup>) = *I* =
(*B*<sup>−1</sup>*A*<sup>−1</sup>)(*AB*), so *AB* is invertible and multiplication is a binary
operation on GL<sub>*n*</sub>(ℝ). The identity matrix is invertible and is an identity element. Each
*A* in GL<sub>*n*</sub>(ℝ) has an inverse *A*<sup>−1</sup>, which is itself invertible, with inverse
*A*. Matrix multiplication is associative.

## Basic properties and multiplication tables

<Video id="9K6rXgxZAgs" title="Basic properties of groups and multiplication tables" duration="33:07" />

From here on the operation of a group is written as juxtaposition: *ab* for *a* ∗ *b*. It is called
the product of *a* and *b*, whatever the operation is.

<Definition n="4.1" title="Abelian group">
A group *G* is **abelian**, or **commutative**, if *ab* = *ba* for all *a*, *b* ∈ *G*.
</Definition>

Commutativity is not one of the group axioms. Abelian groups are those that happen to have it.

<Example n="4.2" title="Abelian and non-abelian groups">
The groups ℤ, ℚ, ℝ and ℂ under addition and ℚ<sup>∗</sup>, ℝ<sup>∗</sup>, ℂ<sup>∗</sup>,
ℚ<sup>+</sup> and ℝ<sup>+</sup> under multiplication are abelian, since the addition and
multiplication of numbers are commutative. The group *S*<sub>3</sub> is not abelian, since
*f*<sub>2</sub>*f*<sub>5</sub> ≠ *f*<sub>5</sub>*f*<sub>2</sub> (Example 1.4). More generally
*S*<sub>*n*</sub> is not abelian for *n* ≥ 3, while *S*<sub>1</sub> and *S*<sub>2</sub> are abelian.
</Example>

<Definition n="4.3" title="Finite group and order">
A group *G* is **finite** if it has finitely many elements. The **order** of a finite group *G*, written
|*G*|, is the number of its elements.
</Definition>

Finiteness depends only on the set, not on the operation.

<Example n="4.4" title="Finite and infinite groups">
For every *n* ≥ 1 the symmetric group *S*<sub>*n*</sub> is finite, of order |*S*<sub>*n*</sub>| = *n*!.
The group *G*<sub>*n*</sub> of *n*th roots of unity is finite. The groups ℤ, ℚ, ℝ, ℂ,
ℚ<sup>∗</sup>, ℝ<sup>∗</sup>, ℂ<sup>∗</sup>, ℚ<sup>+</sup> and ℝ<sup>+</sup> are infinite.
</Example>

The following properties hold in every group, and their proofs use nothing but the group axioms.

<Proposition n="4.5" title="Cancellation">
Let *a*, *b*, *c* be elements of a group *G*. If *ab* = *ac* then *b* = *c*. Likewise, if *ba* = *ca*
then *b* = *c*.
</Proposition>

<Proof>
Multiply both sides of *ab* = *ac* on the left by *a*<sup>−1</sup>, which exists by the inverse axiom:
*a*<sup>−1</sup>(*ab*) = *a*<sup>−1</sup>(*ac*). By associativity, (*a*<sup>−1</sup>*a*)*b* =
(*a*<sup>−1</sup>*a*)*c*, that is, *eb* = *ec*, since *a*<sup>−1</sup>*a* = *e*. As *e* is the
identity, *b* = *c*. The second statement follows in the same way, multiplying on the right by
*a*<sup>−1</sup>.
</Proof>

This is the familiar step of cancelling a common factor from both sides of an equation, made valid in
any group by the axioms.

<Proposition n="4.6" title="The identity is unique">
A group has exactly one identity element.
</Proposition>

<Proof>
Suppose *e* and *e*′ are both identity elements of *G*. Since *e* is an identity, *ee* = *e*. Since
*e*′ is an identity, *ge*′ = *g* for every *g* ∈ *G*, and in particular *ee*′ = *e*. Thus *ee* = *ee*′,
and cancellation (Proposition 4.5) gives *e* = *e*′.
</Proof>

It is therefore correct to speak of *the* identity of a group.

<Proposition n="4.7" title="Inverses are unique">
Each element of a group has exactly one inverse.
</Proposition>

<Proof>
Suppose *g*<sub>1</sub> and *g*<sub>2</sub> are both inverses of *g*. Then *gg*<sub>1</sub> = *e* =
*gg*<sub>2</sub>, and cancellation gives *g*<sub>1</sub> = *g*<sub>2</sub>.
</Proof>

In a group that is not abelian, *g*<sub>1</sub>*g*<sub>2</sub> and *g*<sub>2</sub>*g*<sub>1</sub>
are in general different. When one of them is the identity, however, so is the other.

<Proposition n="4.8" title="A one-sided inverse is the inverse">
If *g*<sub>1</sub> and *g*<sub>2</sub> are elements of a group with *g*<sub>1</sub>*g*<sub>2</sub> =
*e*, then *g*<sub>2</sub> = *g*<sub>1</sub><sup>−1</sup> and *g*<sub>2</sub>*g*<sub>1</sub> = *e*.
</Proposition>

<Proof>
Multiply *g*<sub>1</sub>*g*<sub>2</sub> = *e* on the left by *g*<sub>1</sub><sup>−1</sup>:
*g*<sub>1</sub><sup>−1</sup>(*g*<sub>1</sub>*g*<sub>2</sub>) = *g*<sub>1</sub><sup>−1</sup>*e* =
*g*<sub>1</sub><sup>−1</sup>. By associativity the left side is
(*g*<sub>1</sub><sup>−1</sup>*g*<sub>1</sub>)*g*<sub>2</sub> = *eg*<sub>2</sub> = *g*<sub>2</sub>.
So *g*<sub>2</sub> = *g*<sub>1</sub><sup>−1</sup>, the unique inverse of *g*<sub>1</sub>
(Proposition 4.7), and *g*<sub>2</sub>*g*<sub>1</sub> = *g*<sub>1</sub><sup>−1</sup>*g*<sub>1</sub> =
*e*.
</Proof>

To check that *h* is the inverse of *g*, it is therefore enough to check that *gh* = *e*.

<Definition n="4.9" title="Multiplication table">
The **multiplication table** of a finite group *G* has one row and one column for each element of
*G*, in the same order. The entry in the row of *a* and the column of *b* is the product *ab*.
</Definition>

A multiplication table describes the whole group compactly. Only a finite group has one.

<Example n="4.10" title="The multiplication table of the fourth roots of unity">
The group *G*<sub>4</sub> = \{1, −1, *i*, −*i*\} of Example 3.5 has the multiplication table

|      | 1    | −1   | *i*  | −*i* |
| ---- | ---- | ---- | ---- | ---- |
| 1    | 1    | −1   | *i*  | −*i* |
| −1   | −1   | 1    | −*i* | *i*  |
| *i*  | *i*  | −*i* | −1   | 1    |
| −*i* | −*i* | *i*  | 1    | −1   |

For instance the entry in the row of *i* and the column of −*i* is *i* · (−*i*) = −*i*<sup>2</sup> = 1.
</Example>

In this table each row, and each column, lists every element of the group exactly once, in some order.
This holds in every finite group.

<Proposition n="4.11" title="Rows and columns of a multiplication table">
In the multiplication table of a finite group *G*, every element of *G* appears exactly once in each
row and exactly once in each column.
</Proposition>

<Proof>
The row of *a* lists the products *ab* as *b* runs over *G*. If *ab* = *ac* then *b* = *c* by
cancellation (Proposition 4.5), so no element appears twice in the row. The row has |*G*| entries, all
distinct, so every element of *G* appears in it. The column of *b* lists the products *ab* as *a* runs
over *G*, and the same argument applies, using the cancellation *ab* = *cb* ⇒ *a* = *c*.
</Proof>

This gives a check on a computed table: an element that is repeated, or missing, in some row or column
signals an error.

## Deciding whether a set is a group

<Video id="PQL3lv35KxU" title="Deciding whether a set is a group" duration="25:48" />

To decide whether a set with an operation is a group, check each of closure, identity, inverses and
associativity in turn. A natural operation on a familiar set may fail some of them, and a set that is
not a group can sometimes be made into one by adding elements to it or by removing some.

<Example n="5.1" title="Subtraction on the integers">
Define *a* ∗ *b* = *a* − *b* on ℤ. The difference of two integers is an integer, so ∗ is a binary
operation. Since *a* ∗ 0 = *a* for every *a*, the only candidate for an identity is 0, but
0 ∗ *a* = −*a*, which differs from *a* when *a* ≠ 0. So there is no identity element. Nor is ∗
associative: 5 ∗ (3 ∗ 2) = 5 − 1 = 4, while (5 ∗ 3) ∗ 2 = 2 − 2 = 0. So (ℤ, ∗) is not a group.
</Example>

<Example n="5.2" title="A new operation on the integers">
Define *a* ∗ *b* = *a* + *b* + *ab* on ℤ; for instance 3 ∗ 5 = 3 + 5 + 15 = 23. This is a binary
operation on ℤ, and 0 is an identity, since *a* ∗ 0 = *a* + 0 + 0 = *a* and 0 ∗ *a* = *a*. It is
associative, since

<Display>(*a* ∗ *b*) ∗ *c* = (*a* + *b* + *ab*) + *c* + (*a* + *b* + *ab*)*c* = *a* + *b* + *c* + *ab* + *ac* + *bc* + *abc*,</Display>

and expanding *a* ∗ (*b* ∗ *c*) = *a* + (*b* + *c* + *bc*) + *a*(*b* + *c* + *bc*) gives the same seven
terms. But an inverse *b* of *a* must satisfy *a* + *b* + *ab* = 0, that is, *b*(1 + *a*) = −*a*, so
*b* = −*a*/(1 + *a*). For *a* = 2 this is −2/3, which is not an integer. So (ℤ, ∗) has three of the
four properties, but it is not a group.
</Example>

<Proposition n="5.3" title="Removing −1 from the rationals">
Let *G* = ℚ ∖ \{−1\}, with *a* ∗ *b* = *a* + *b* + *ab*. Then (*G*, ∗) is a group.
</Proposition>

<Proof>
Note that *a* ∗ *b* = (1 + *a*)(1 + *b*) − 1. If *a*, *b* ∈ *G* then 1 + *a* and 1 + *b* are non-zero,
so (1 + *a*)(1 + *b*) ≠ 0 and *a* ∗ *b* ≠ −1; thus ∗ is a binary operation on *G*. As in Example 5.2,
0 ∈ *G* is an identity and ∗ is associative. For *a* ∈ *G* let *b* = −*a*/(1 + *a*), which is a
rational number because *a* ≠ −1. Then *a* + *b* + *ab* = *a* + *b*(1 + *a*) = *a* − *a* = 0, and
likewise *b* ∗ *a* = 0. Finally *b* ≠ −1, for otherwise −*a* = −1 − *a*. So *b* ∈ *G* is an inverse of
*a*.
</Proof>

On ℤ inverses are missing; enlarging the set to ℚ supplies all of them except an inverse of −1, and
removing −1 yields a group.

<Definition n="5.4" title="Coprime integers; reduced form">
Integers *a* and *b* are **coprime** if they have no common factor other than ±1. For example, 6 and
10 are not coprime, as 2 divides both, while 6 and 25 are. A rational number *a*/*b* with *b* > 0 is
in **reduced form** if *a* and *b* are coprime; every rational number has a unique reduced form,
obtained by cancelling common factors.
</Definition>

<Example n="5.5" title="Fractions whose denominator is divisible by 5">
Let *G* be the set of rational numbers whose reduced form *a*/*b* has 5 dividing *b*. Membership must
be read from the reduced form: 1/5 ∈ *G*, but 1/4 ∉ *G*, even though 1/4 = 5/20. Under addition,
*G* is not closed: 2/5 and 3/5 lie in *G*, but 2/5 + 3/5 = 1 = 1/1, and 5 does not divide 1. So
*G* is not a group under addition.
</Example>

<Proposition n="5.6" title="Fractions whose denominator is prime to 5">
Let *G*′ be the set of rational numbers whose reduced form *a*/*b* has 5 not dividing *b*. Then *G*′ is
a group under addition.
</Proposition>

<Proof>
Let *a*/*b* and *c*/*d* be in *G*′, in reduced form, so that 5 divides neither *b* nor *d*. Their sum
is (*ad* + *bc*)/*bd*. Since 5 is prime and divides neither *b* nor *d*, it does not divide *bd*. This
fraction may not be in reduced form, but reducing it only cancels factors, so the reduced denominator
divides *bd* and is not divisible by 5 either. Hence the sum lies in *G*′. The identity 0 = 0/1 lies
in *G*′, as 5 does not divide 1. The inverse of *a*/*b* is −*a*/*b*, which has the same denominator
and so lies in *G*′. Addition is associative because it is associative on ℚ.
</Proof>

Changing the condition on the denominator from “divisible by 5” to “not divisible by 5” turns a set
that is not even closed under addition into a group.

## Powers of an element in a finite group

<Video id="P5XhJg_JN1U" title="Powers of an element in a finite group" duration="22:19" />

The problems in this section concern an arbitrary group, so their solutions may use only the group
axioms and what follows from them, and no property special to numbers, functions or any other
example.

<Definition n="6.1" title="Powers of an element">
Let *a* be an element of a group *G* and *n* a positive integer. The **power** *a*<sup>*n*</sup> is the
product *aa* ⋯ *a* of *n* copies of *a*. Further, *a*<sup>0</sup> = *e* and
*a*<sup>−*n*</sup> = (*a*<sup>−1</sup>)<sup>*n*</sup>.
</Definition>

By associativity a product of several elements has the same value however it is bracketed, so
*a*<sup>*n*</sup> is well defined. Each power of *a* lies in *G*, because the operation is closed.

<Proposition n="6.2" title="Some power of each element is the identity">
If *G* is a finite group and *a* ∈ *G*, there is a positive integer *n* with *a*<sup>*n*</sup> = *e*.
</Proposition>

<Proof>
The powers *a*, *a*<sup>2</sup>, *a*<sup>3</sup>, … all lie in *G*. If they were all distinct, they would
form an infinite subset of the finite set *G*, which is impossible. So *a*<sup>*n*</sup> =
*a*<sup>*m*</sup> for some positive integers *n* ≠ *m*, and we may take *n* > *m*. Multiply both sides
on the right by (*a*<sup>−1</sup>)<sup>*m*</sup>. On the right-hand side the *m* copies of *a* cancel
against the *m* copies of *a*<sup>−1</sup> one pair at a time, from the middle outwards, since
*aa*<sup>−1</sup> = *e*, leaving *e*. On the left-hand side the same cancellation removes *m* of the
*n* copies of *a*, leaving *a*<sup>*n*−*m*</sup>. So *a*<sup>*n*−*m*</sup> = *e*, and *n* − *m* is a
positive integer.
</Proof>

For instance, if *a*<sup>5</sup> = *a*<sup>3</sup>, multiplying by (*a*<sup>−1</sup>)<sup>3</sup> cancels
three copies of *a* on each side and gives *a*<sup>2</sup> = *e*.

<Example n="6.3" title="The integers under addition">
Proposition 6.2 fails for infinite groups. In ℤ under addition the *n*th power of 1 is the sum
1 + 1 + ⋯ + 1 of *n* ones, which is *n*. The identity is 0, and *n* ≠ 0 for every positive integer
*n*.
</Example>

<Lemma n="6.4" title="Multiples of an exponent">
If *a*<sup>*n*</sup> = *e* and *n* divides *m*, where *n* and *m* are positive integers, then
*a*<sup>*m*</sup> = *e*.
</Lemma>

<Proof>
Write *m* = *nk*. By associativity the product of *m* copies of *a* may be grouped into *k* blocks of
*n* copies each, so *a*<sup>*m*</sup> = (*a*<sup>*n*</sup>)<sup>*k*</sup> = *e*<sup>*k*</sup> = *e*.
</Proof>

In Proposition 6.2 the integer *n* may depend on *a*. In a finite group a single exponent serves for
every element.

<Proposition n="6.5" title="One exponent for every element">
If *G* is a finite group, there is a positive integer *N* with *a*<sup>*N*</sup> = *e* for every
*a* ∈ *G*.
</Proposition>

<Proof>
Let *G* = \{*a*<sub>1</sub>, …, *a*<sub>*r*</sub>\}. By Proposition 6.2 there are positive integers
*n*<sub>1</sub>, …, *n*<sub>*r*</sub> with *a*<sub>*k*</sub><sup>*n*<sub>*k*</sub></sup> = *e* for each
*k*. Let *N* = *n*<sub>1</sub>*n*<sub>2</sub> ⋯ *n*<sub>*r*</sub>. Each *n*<sub>*k*</sub> divides
*N*, so *a*<sub>*k*</sub><sup>*N*</sup> = *e* by Lemma 6.4.
</Proof>

## Groups of order at most five are abelian

<Video id="8nof6OH5e8k" title="Groups of order at most five are abelian" duration="35:13" />

The group *S*<sub>3</sub> has order 6 and is not abelian. No smaller group fails to be abelian, and
the proof uses nothing but the group axioms and their first consequences.

A group *G* fails to be abelian exactly when it has two elements *a* and *b* with *ab* ≠ *ba*. The
proof shows that a group with five or fewer elements has no room for such a pair.

<Lemma n="7.1" title="Elements that do not commute">
Every element of a group commutes with the identity and with its own inverse. If *ab* ≠ *ba*, then
*e*, *a*, *b* are distinct, and neither *ab* nor *ba* is equal to *e*, *a* or *b*.
</Lemma>

<Proof>
*ae* = *a* = *ea*, and *aa*<sup>−1</sup> = *e* = *a*<sup>−1</sup>*a*. Now suppose *ab* ≠ *ba*. Then
*a* ≠ *e* and *b* ≠ *e*, since each commutes with *e*, and *a* ≠ *b*, since *a* commutes with itself.
If *ab* = *e* then *ba* = *e* by Proposition 4.8, so *ab* = *ba*; hence *ab* ≠ *e*. If *ab* = *a* = *ae*,
cancellation gives *b* = *e*; if *ab* = *b* = *eb*, it gives *a* = *e*. Neither is possible. The same
arguments apply to *ba*.
</Proof>

<Theorem n="7.2" title="Groups of order at most five are abelian">
Every group of order at most 5 is abelian.
</Theorem>

<Proof>
A group contains its identity, so |*G*| ≥ 1. Consider each order in turn.

*Order 1 or 2.* Then *G* = \{*e*\} or *G* = \{*e*, *a*\}, and every element commutes with *e*.

*Order 3.* Let *G* = \{*e*, *a*, *b*\}. The only pair that might not commute is *a*, *b*. The product
*ab* lies in *G*. It is not *a*, for *ab* = *a* = *ae* gives *b* = *e*, and not *b*, for *ab* = *b*
gives *a* = *e*. So *ab* = *e*, and then *ba* = *e* by Proposition 4.8.

*Order 4.* Suppose *ab* ≠ *ba*. By Lemma 7.1, *e*, *a*, *b* are three distinct elements and *ab* is none
of them, so *G* = \{*e*, *a*, *b*, *ab*\}. But *ba* is also none of *e*, *a*, *b*, so *ba* = *ab*, a
contradiction.

*Order 5.* Suppose *ab* ≠ *ba*. By Lemma 7.1 the elements *e*, *a*, *b*, *ab*, *ba* are distinct, so

<Display>*G* = \{*e*, *a*, *b*, *ab*, *ba*\}.</Display>

First, *aba* = *b*. The product *aba* is one of the five elements. If *aba* = *e*, then *a*(*ba*) = *e*
and (*ab*)*a* = *e*, so both *ba* and *ab* are inverses of *a*, and *ab* = *ba* by Proposition 4.7. If
*aba* = *a*, cancelling *a* on the left gives *ba* = *e*, which Lemma 7.1 excludes. If *aba* = *ab*,
cancelling *ab* on the left gives *a* = *e*; if *aba* = *ba*, cancelling *ba* on the right gives
*a* = *e*. Only *aba* = *b* remains. In the same way, with the roles of *a* and *b* exchanged,
*bab* = *a*.

Second, *a*<sup>2</sup> = *b*<sup>2</sup>. Multiplying *aba* = *b* on the left by *b* gives *baba* =
*b*<sup>2</sup>, and multiplying *bab* = *a* on the right by *a* gives *baba* = *a*<sup>2</sup>.

Third, *a*<sup>2</sup> = *e*. If *a*<sup>2</sup> = *a*, cancelling gives *a* = *e*. If
*a*<sup>2</sup> = *b*, then *b*<sup>2</sup> = *a*<sup>2</sup> = *b*, and cancelling gives *b* = *e*. If
*a*<sup>2</sup> = *ab*, cancelling *a* on the left gives *a* = *b*; if *a*<sup>2</sup> = *ba*,
cancelling *a* on the right gives *a* = *b*. Each is impossible, so *a*<sup>2</sup> = *e*, and
therefore *b*<sup>2</sup> = *e* too.

Finally, multiply *bab* = *a* on the right by *b*: *bab*<sup>2</sup> = *ab*. Since *b*<sup>2</sup> =
*e*, this says *ba* = *ab*, a contradiction. So every group of order 5 is abelian.
</Proof>

Since *S*<sub>3</sub> is not abelian, 6 is the smallest order of a group that is not abelian.
